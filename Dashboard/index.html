Keterangan warna kotak

Keadaan truk (kotak tebal)

  • Bergerak: truk sedang berjalan
  • Dimuat: berhenti di dekat excavator
  • Dumping: berhenti dengan bak terangkat
  • Idle: berhenti tanpa dilayani

Angka di belakangnya, misalnya "Dimuat 24 dtk", adalah lama truk dalam keadaan itu. Keadaan ini kesimpulan backend dari gerak truk dan objek di sekitarnya, bukan hasil model.

Hasil deteksi model (kotak putus-putus)

  • Excavator: alat gali pemuat
  • Bak terangkat: truk sedang menumpahkan muatan
  • Bermuatan / Kosong: isi bak truk

Pilih "Deteksi Frigate" di atas untuk melihat kotak asli dari Frigate; warnanya mengikuti Frigate (lihat README proyek).
